    L1 Regularization (Lasso)

    L1 regularization adds the absolute values of the model coefficients to the loss function. In linear models, it is commonly known as Lasso (Least Absolute Shrinkage and Selection Operator).

    Its defining behavior is simple:

    L1 can shrink some coefficients all the way to exactly zero, so it can perform feature selection while fitting the model.

    The objective function

    For coefficients \(w_1, w_2, \ldots, w_p\), the regularized objective is

    \[ \mathcal{L}_{L1}(w) = \mathcal{L}_{\text{original}}(w) + \lambda \sum_{j=1}^{p}|w_j| \]

    where:

    • \(\mathcal{L}_{\text{original}}\) measures prediction error;
    • \(\sum |w_j|\) measures model complexity;
    • \(\lambda \ge 0\) controls the strength of the penalty.

    The intercept is usually not penalized. Because the penalty depends on coefficient size, numerical features should normally be standardized before applying L1.

    flowchart LR A[Prediction error] --> C[Regularized objective] B["L1 penalty: lambda × sum of absolute coefficients"] --> C C --> D{Choose coefficients that minimize both} D --> E[Good fit] D --> F[Few non-zero coefficients]

    What \(\lambda\) changes

    Penalty strength Typical result Interpretation
    \(\lambda = 0\) Original model No regularization
    Small \(\lambda\) Coefficients become smaller Mild protection against overfitting
    Medium \(\lambda\) Some coefficients become zero Sparse model and feature selection
    Very large \(\lambda\) Most or all coefficients become zero Likely underfitting

    A simplified coefficient path makes the sparsity effect visible:

    \(x_1\) 1.20 1.02 0.71 0.18
    \(x_2\) 0.55 0.34 0.00 0.00
    \(x_3\) -0.30 -0.12 0.00 0.00

    Why L1 creates zeros

    With two coefficients, the constraint \(|w_1|+|w_2|\leq t\) forms a diamond. The corners lie on the axes, where one coefficient is zero. As the loss contours expand toward the feasible region, they often touch one of those corners first.

                             w2
                          ▲
                          │
                     (0, t)  ← corner: w1 = 0
                        / \
                       /   \
          (-t, 0) ────◆─────◆────── (t, 0)  ──▶ w1
                       \   /
                        \ /
                     (0,-t)  ← corner: w1 = 0

                  L1 feasible region: |w1| + |w2| ≤ t

    This geometry explains why L1 produces sparse solutions. It is not merely making every coefficient a little smaller; it can remove variables from the fitted model.

    When L1 is useful

    L1 is a strong choice when:

    • the dataset has many features and only a subset is expected to matter;
    • a compact, interpretable model is desirable;
    • automatic feature selection is useful;
    • reducing overfitting is more important than retaining every variable.

    Be careful when predictors are strongly correlated. L1 may keep one variable and discard another with similar predictive information, and that choice can be unstable across samples. If grouped retention is important, consider L2 or Elastic Net.

    Practical workflow

    1. Standardize numeric predictors.
    2. Select \(\lambda\) with cross-validation rather than the training error.
    3. Refit using the selected value.
    4. Inspect both validation performance and the number of non-zero coefficients.
    5. Confirm stability on unseen or out-of-time data.

    L1 versus L2 at a glance

    Property L1 (Lasso) L2 (Ridge)
    Penalty $\sum w_j
    Coefficients Some become exactly zero Usually remain non-zero
    Feature selection Yes No
    Correlated features Often selects a subset Tends to share weight
    Resulting model Sparse Dense and stable
