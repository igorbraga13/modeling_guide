Ensemble de árvores independentes construídas com amostragem bootstrap (bagging).

Todas as árvores são construídas em paralelo. Os resultados são agregados (média para regressão, maioria para classificação).

Não faz otimização explícita, apenas agrega resultados.

Não possui regularização explícita.

Funciona bem em muitos problemas, menos sensível a overfitting com muitos dados.

permite ver a importância média das variáveis.
