Em um projeto de regressão, uma combinação razoável é:

- MAE, para uma interpretação direta do erro médio.
- RMSE, para identificar o impacto de erros grandes.
- R², para medir a variabilidade explicada.
- R² ajustado, para regressão estatística com diferentes quantidades de variáveis.

## Análise de Resíduos

- Resíduos versus valores previstos.
- Distribuição e normalidade dos resíduos.
- Homocedasticidade. (É verificada analisando se a variância dos resíduos permanece aproximadamente constante ao longo dos valores previstos. Gráfico de resíduos vs valores previstos)
- Autocorrelação. (Verifica se os resíduos estão correlacionados entre si, especialmente em dados temporais. Gráfico de resíduos ao longo do tempo)
- Outliers e observações influentes.
- Multicolinearidade entre variáveis.
