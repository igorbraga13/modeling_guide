
| Termo                     | O que é                                               | Granularidade                                     | Exemplo                                         |
| ------------------------- | ----------------------------------------------------- | ------------------------------------------------- | ----------------------------------------------- |
| **Épico**                 | Um grande bloco de trabalho                           | Muito alta                                        | "Reestruturar todo o sistema de recomendação"   |
| **História (User Story)** | Uma funcionalidade vista do ponto de vista do usuário | Média                                             | "Como cliente, quero ver recomendações na home" |
| **Tarefa**                | Subparte de uma história                              | Baixa                                             | "Criar endpoint para recomendações"             |
| **Card**                  | Representação visual no Kanban                        | Pode ser qualquer nível (épico, história, tarefa) | — depende de como o time organiza               |

🧩 Definições práticas

✅ Épico

- Um conjunto de histórias relacionadas que compõem uma iniciativa maior.
- Pode durar várias sprints ou semanas.
- Serve para organizar o roadmap em alto nível.

✅ História de Usuário (User Story)

- Descreve o que o usuário precisa e por quê.
- Formato comum:

        "Como [tipo de usuário], quero [ação] para [benefício]."

- Usada para detalhar funcionalidades concretas.

✅ Tarefa (Task)

- Ações técnicas para implementar uma história.
- Visão interna da equipe.
- Pode ou não ser visível no Kanban (depende do detalhamento do time).

✅ Card

- Item visual em um quadro Kanban.
- Pode representar qualquer uma das opções acima, dependendo da configuração do time (ex: cards para histórias, ou cards para tarefas).
- Possui status (To Do, Doing, Done), responsável, comentários, etc.
