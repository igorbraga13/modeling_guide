# Specialized Ensembles

| Algorithm                                                   | Description                                                              | Use Case                          |
| ----------------------------------------------------------- | ------------------------------------------------------------------------ | --------------------------------- |
| **Gradient Boosted Decision Rules (GBDR)**                  | Boosting trees that output human-readable rules.                         | Explainable AI in tabular models. |
| **Snapshot Ensembles**                                      | Deep learning ensemble using multiple checkpoints from one training run. | Neural Networks (regularization). |
| **Bagging + Boosting Hybrids (e.g., RUSBoost, SMOTEBoost)** | Combine sampling and boosting for imbalanced data.                       | Credit scoring, fraud detection.  |
