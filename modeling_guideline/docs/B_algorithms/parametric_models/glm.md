

## Logistic Regression

$$P(y=1|x) = \frac{1}{1+e-^{(\beta_0 + \beta_1x)}}$$

Onde:

- P(y = 1|x) é a probabilidade do evento ocorrer dado x;
- β0 é o intercepto;
- β1 é o coeficiente da variável x;
- e é a base do logaritmo natural.

Essa função é conhecida como função sigmoide, que transforma qualquer valor real em um valor entre 0 e 1.

Sigmoid $$\frac{1}{1+ e^{-x}}$$
