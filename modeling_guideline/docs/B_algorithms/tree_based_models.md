| Category                       | Algorithm                                                              | Description                                                                           | Typical Use Cases                                    |
| ------------------------------ | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| **Classical Decision Trees**   | **CART (Classification and Regression Tree)**                          | Binary splits minimizing impurity (Gini, Entropy, or MSE).                            | Credit scoring, risk modeling, regression baselines. |
|                                | **ID3 (Iterative Dichotomiser 3)**                                     | Early decision tree using Information Gain as split criterion.                        | Educational and illustrative examples.               |
|                                | **C4.5**                                                               | Successor to ID3; handles continuous variables and missing values.                    | Customer segmentation, marketing, churn.             |
|                                | **C5.0**                                                               | Commercially improved version of C4.5 (faster, pruning optimized).                    | Business decision trees, scoring engines.            |
|                                | **CHAID (Chi-squared Automatic Interaction Detector)**                 | Multiway splits using statistical tests (Chi-square, F-tests).                        | Marketing analytics, behavioral segmentation.        |
| **Model Trees**                | **M5 / M5P**                                                           | Regression trees with local linear models in the leaves.                              | Predicting continuous outcomes with interactions.    |
|                                | **Cubist**                                                             | Advanced M5 implementation with linear rules in leaves.                               | Forecasting, energy and sales modeling.              |
| **Conditional Trees**          | **CTree (Conditional Inference Tree)**                                 | Uses statistical tests (p-values) for unbiased splits.                                | Datasets with categorical imbalance or many levels.  |
|                                | **GUIDE (Generalized, Unbiased Interaction Detection and Estimation)** | Adjusts for bias in variable selection; supports missing values.                      | Complex categorical datasets, survey data.           |
| **Oblique & Hybrid Trees**     | **Oblique Decision Tree (ODT)**                                        | Splits use linear combinations of variables instead of one feature.                   | High-dimensional data, when axes are not aligned.    |
|                                | **QUEST (Quick, Unbiased, Efficient Statistical Tree)**                | Statistically unbiased tree-growing algorithm.                                        | Medical data, balanced and unbiased classification.  |
|                                | **REPTree**                                                            | Fast regression/classification tree using information gain and reduced-error pruning. | Baseline modeling in large tabular datasets.         |
| **Rule Extraction from Trees** | **PART (Partial Decision Tree)**                                       | Derives interpretable rules from partial trees.                                       | Explainable models, compliance analysis.             |
|                                | **RIPPER (Repeated Incremental Pruning to Produce Error Reduction)**   | Generates decision rules directly, inspired by tree structure.                        | Fraud detection, compliance, rule-based scoring.     |
